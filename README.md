# Coastal Unicorn — Website

Marketing site for Coastal Unicorn (brands, websites & AI automation for Gulf Coast small businesses).

## Structure
- `index.html` — homepage
- `coastal-unicorn-logo.png` — logo
- `examples/` — live client demo sites
  - `lash-and-co/` — luxury lash studio demo
  - `artist-music/` — editorial musician portfolio demo
  - `pet-grooming/` — boutique pet grooming demo

## Deploys
This site is hosted on Netlify. When connected to GitHub, every push to the
`main` branch publishes automatically to https://coastalunicorn.com
(no build step — it's a static site, publish directory is the repo root).
